Firebase কনফিগার করা হয়নি

এই ফাইলের <script> অংশের শুরুতে FIREBASE_CONFIG-এ আপনার প্রজেক্টের মান বসান (index.html-এ যে মান বসিয়েছেন সেটাই)।

  1. Firebase Console → Project settings → Your apps → Web app
  2. config-এর মানগুলো কপি করে এই ফাইলে বসান
  3. Authentication → Sign-in method → Email/Password চালু করুন
  4. ফাইল সেভ করে আবার খুলুন
